# Ma Tréso — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Livrer l'app web responsive « Ma Tréso » (projection de trésorerie sur 15 mois pour freelances) décrite dans `SPEC.md`, déployable en une image Docker.

**Architecture:** Monorepo npm workspaces. `packages/engine` est un moteur de calcul TypeScript pur (ESM), partagé par le front et l'API. `apps/api` est une API NestJS 12 (ESM) avec Drizzle et PostgreSQL 16 ; elle gère l'auth (mot de passe et passkeys), le CRUD, la validation et l'export/import, et sert le build statique du front. `apps/web` est un front Nuxt 4 en SPA avec Pinia : les projections sont calculées dans le navigateur et les écritures sont optimistes.

**Tech Stack:** Node 24, TypeScript ~5.9 (strict), Vitest, NestJS 12, Drizzle ORM + drizzle-kit, PostgreSQL 16, zod 4, @node-rs/argon2, @simplewebauthn 14, Nuxt 4.5, Pinia, @vite-pwa/nuxt, Playwright, Docker (node:24-alpine).

**Spec:** `docs/superpowers/specs/2026-10-04-ma-treso-design.md` (spec technique) et `SPEC.md` (spec produit, qui fait foi pour les règles). Maquettes : `design/ma-treso-design/ecrans/*.dc.html`.

**Fichiers du plan :**
1. Ce fichier : contraintes, Review Focus, conventions, **Phase 0 (socle) et Phase 1 (moteur)**.
2. `2026-10-04-ma-treso-api.md` : **Phase 2 (API)**.

## Global Constraints

- Node : `>=24.11` (Nuxt 4.5 exige `^22.19 || ^24.11`). En local sous Windows, **chaque commande shell** commence par `export PATH="/c/Users/guill/AppData/Roaming/nvm/v24.14.0:$PATH"` (bash). Ne jamais lancer `nvm use`, qui modifie le Node global partagé.
- TypeScript : épinglé à `~5.9` dans tous les workspaces (TS 7 est sorti, mais l'émission `emitDecoratorMetadata` dont NestJS a besoin n'y est pas garantie). `strict: true` et `noUncheckedIndexedAccess: true`.
- Tous les montants sont des **entiers en centimes**, et toutes les dates des chaînes `YYYY-MM-DD` sans fuseau horaire. L'arrondi à la dizaine d'euros se fait uniquement à l'affichage (`format.ts`).
- Le moteur ne lit jamais l'horloge : `today` est toujours passé en paramètre.
- Aucun calcul métier dans les composants Vue : ils appellent le moteur via le store et formatent l'affichage.
- Interface en français, au tutoiement. Format FR : séparateur de milliers U+202F, `€` après le nombre précédé de U+00A0, signe moins U+2212, « 5,3k » dans les graphiques.
- URLs en anglais : `/login`, `/`, `/clients`, `/clients/new`, `/clients/:id`, `/calendar`, `/expenses`, `/profile`. Toute l'API vit sous `/api`.
- Auth v1 : e-mail et mot de passe, plus passkeys. **Pas** de lien magique ni d'envoi d'e-mail : « Mot de passe oublié » affiche « Bientôt disponible ».
- Jetons de couleur (SPEC §7.1), polices Bricolage Grotesque (titres et chiffres) et Figtree (texte), rayons de 26 px pour les cartes et de 28–30 px pour la carte verdict, ombre `0 4px 0 rgba(31,26,46,.05)`.
- Accessibilité : cibles ≥ 44 × 44 px, aucun défilement horizontal à 390 px, `aria-pressed` sur les pastilles, `role="switch"` sur les interrupteurs, `role="status"` sur les alertes, `aria-label` sur les boutons icône et sur chaque barre de graphique (« février 2027 : −2 310 € »). Jamais d'emoji.
- Mention sur les estimations : « Estimation simplifiée, à affiner avec ton expert-comptable ».
- Commits : Conventional Commits en français, terminés par la ligne `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Tests et dev locaux sans Docker** : la base est PGlite (PostgreSQL embarqué, `@electric-sql/pglite`), via `DATABASE_URL=pglite:memory` (tests) ou `pglite:<dossier>` (dev). PostgreSQL 16 (`pg`) ne sert qu'en production, avec l'image Docker. Un seul schéma Drizzle `pg-core` pour les deux. Docker n'est requis que pour construire et tester l'image (Task 34, vérification optionnelle si le démon est disponible).

## Review Focus

Cinq cas que la spec implique sans qu'aucun test de tâche ne les couvre spontanément. Chacun a son test dans la tâche indiquée.

1. **Compte neuf et vide** (aucun client, aucune charge, aucun solde) : la projection part de 0 €, chaque écran affiche son état vide, sans `NaN` ni plantage. Tests : Task 9 (`monthResults` sur une entrée vide), Task 26 (rendu du dashboard sans données, voir le fichier web).
2. **Date du jour en local près de minuit et hors UTC** : `today` doit venir des composantes locales (`getFullYear`/`getMonth`/`getDate`), jamais de `toISOString()`. Test : Task 2 (`localToday`).
3. **Horizon qui déborde sur une année sans paramètres** (2028 et au-delà) : repli sur la dernière année connue, fériés calculés pour n'importe quelle année. Test : Task 3 (`paramsFor(2030)`, Pâques 2030).
4. **Import d'un fichier JSON invalide ou étranger** : réponse 400 avec un message lisible, et **aucune** donnée existante modifiée. Test : Task 20 (fichier API).
5. **Saisies incohérentes sur une mission** : fin avant début, TJM sans aucun jour de présence, tarifs tous futurs. On attend un refus 422 pour la fin avant le début, et un montant de 0 € sans plantage pour les deux autres cas. Tests : Task 5 (`weekdays: []`, tarifs futurs), Task 18 (fichier API, `END_BEFORE_START`).

## Conventions de code

- Moteur : un module par responsabilité (voir la liste des fichiers ci-dessous), fonctions exportées nommées, aucune classe, aucune dépendance runtime. Imports relatifs **sans extension** : le moteur est bundlé par tsup.
- API : ESM, `module: NodeNext`, donc imports relatifs **avec l'extension `.js`**. Un dossier par feature.
- Web : composants `PascalCase.vue`, composables `useXxx.ts`, CSS scoped. Le balisage des maquettes est porté **à l'identique** : mêmes textes, mêmes tailles, mêmes couleurs, et les styles en ligne statiques deviennent des classes scoped.
- Tests : `*.test.ts` (Vitest) pour le moteur, `*.e2e.test.ts` pour l'API, `*.spec.ts` (Playwright) pour le front.

```ts
export type ISODate = string;
export type MonthKey = string;

const DAY_MS = 86_400_000;
const ISO_RE = /^(\d{4})-(\d{2})-(\d{2})$/;

const pad = (n: number): string => String(n).padStart(2, '0');

export function isISODate(value: string): boolean {
  const m = ISO_RE.exec(value);
  if (!m) return false;
  const y = Number(m[1]);
  const mo = Number(m[2]);
  const d = Number(m[3]);
  const dt = new Date(Date.UTC(y, mo - 1, d));
  return dt.getUTCFullYear() === y && dt.getUTCMonth() === mo - 1 && dt.getUTCDate() === d;
}

export function toEpochDay(iso: ISODate): number {
  const m = ISO_RE.exec(iso);
  if (!m) throw new Error(`Invalid ISO date: ${iso}`);
  return Date.UTC(Number(m[1]), Number(m[2]) - 1, Number(m[3])) / DAY_MS;
}

export function fromEpochDay(day: number): ISODate {
  const dt = new Date(day * DAY_MS);
  return `${dt.getUTCFullYear()}-${pad(dt.getUTCMonth() + 1)}-${pad(dt.getUTCDate())}`;
}

export const addDays = (iso: ISODate, n: number): ISODate => fromEpochDay(toEpochDay(iso) + n);

export const diffDays = (from: ISODate, to: ISODate): number => toEpochDay(to) - toEpochDay(from);

/** 0 = lundi … 6 = dimanche. Le 1970-01-01 était un jeudi. */
export function weekday(iso: ISODate): number {
  return (((toEpochDay(iso) + 3) % 7) + 7) % 7;
}

export const monthKey = (iso: ISODate): MonthKey => iso.slice(0, 7);
export const yearOf = (isoOrMonth: string): number => Number(isoOrMonth.slice(0, 4));
export const monthIndex = (isoOrMonth: string): number => Number(isoOrMonth.slice(5, 7)) - 1;

export function addMonths(month: MonthKey, n: number): MonthKey {
  const total = yearOf(month) * 12 + monthIndex(month) + n;
  return `${Math.floor(total / 12)}-${pad((total % 12) + 1)}`;
}

export const firstDayOfMonth = (month: MonthKey): ISODate => `${month}-01`;

export function daysInMonth(month: MonthKey): number {
  return new Date(Date.UTC(yearOf(month), monthIndex(month) + 1, 0)).getUTCDate();
}

export const lastDayOfMonth = (month: MonthKey): ISODate => `${month}-${pad(daysInMonth(month))}`;

export function monthRange(first: MonthKey, count: number): MonthKey[] {
  return Array.from({ length: count }, (_, i) => addMonths(first, i));
}

export function eachDay(from: ISODate, to: ISODate): ISODate[] {
  const out: ISODate[] = [];
  for (let d = toEpochDay(from), end = toEpochDay(to); d <= end; d++) out.push(fromEpochDay(d));
  return out;
}

export const eachDayOfMonth = (month: MonthKey): ISODate[] => eachDay(firstDayOfMonth(month), lastDayOfMonth(month));

export const minDate = (a: ISODate, b: ISODate): ISODate => (a < b ? a : b);
export const maxDate = (a: ISODate, b: ISODate): ISODate => (a > b ? a : b);

/** Date civile locale. Utilisée par les appelants (front, API) ; le moteur ne l'appelle jamais. */
export function localToday(now: Date = new Date()): ISODate {
  return `${now.getFullYear()}-${pad(now.getMonth() + 1)}-${pad(now.getDate())}`;
}
```

export function easterSunday(year: number): ISODate {
  const a = year % 19;
  const b = Math.floor(year / 100);
  const c = year % 100;
  const d = Math.floor(b / 4);
  const e = b % 4;
  const f = Math.floor((b + 8) / 25);
  const g = Math.floor((b - f + 1) / 3);
  const h = (19 * a + b - d - g + 15) % 30;

  const l = (32 + 2 * e + 2 * i - h - k) % 7;
  const m = Math.floor((a + 11 * h + 22 * l) / 451);
  const month = Math.floor((h + l - 7 * m + 114) / 31);
  const day = ((h + l - 7 * m + 114) % 31) + 1;
  return `${year}-${pad(month)}-${pad(day)}`;

import { addDays, type ISODate } from './dates';
import type { Cents, Client, Rate } from './types';

export function sortRates(rates: readonly Rate[]): Rate[] {
  return [...rates].sort((a, b) => a.validFrom.localeCompare(b.validFrom));
}

/** Montant du tarif dont validFrom est le plus grand ≤ date, sinon 0 (SPEC §4.2). */
export function rateAt(client: Pick<Client, 'rates'>, date: ISODate): Cents {
  let amount = 0;
  for (const r of sortRates(client.rates)) {
    if (r.validFrom > date) break;
    amount = r.amount;
  }
  return amount;
}

/** Tarif en vigueur aujourd'hui ; à défaut (tous futurs), le premier tarif. Sert à l'affichage « TJM actuel ». */
export function currentRate(client: Pick<Client, 'rates'>, today: ISODate): Rate | null {
  const sorted = sortRates(client.rates);
  let current: Rate | null = null;
  for (const r of sorted) if (r.validFrom <= today) current = r;
  return current ?? sorted[0] ?? null;
}

/** Prochain tarif futur, différent du tarif affiché comme actuel. */
export function nextRate(client: Pick<Client, 'rates'>, today: ISODate): Rate | null {
  const current = currentRate(client, today);
  return sortRates(client.rates).find((r) => r.validFrom > today && r !== current) ?? null;
}

export type RateStatus = 'PAST' | 'CURRENT' | 'FUTURE';

export interface RateRow {
  rate: Rate;
  status: RateStatus;
  /** Dernier jour d'application (veille du tarif suivant), null pour le dernier tarif */
  validTo: ISODate | null;
}

export function rateHistory(rates: readonly Rate[], today: ISODate): RateRow[] {
  const sorted = sortRates(rates);
  let currentIdx = -1;
  sorted.forEach((r, i) => {
    if (r.validFrom <= today) currentIdx = i;
  });
  return sorted.map((rate, i) => {
    const next = sorted[i + 1];
    return {
      rate,
      status: i === currentIdx ? 'CURRENT' : rate.validFrom > today ? 'FUTURE' : 'PAST',
      validTo: next ? addDays(next.validFrom, -1) : null,
    };
  });
}

import { daysInMonth, eachDayOfMonth, type ISODate, type MonthKey, weekday } from './dates';
import { isHoliday } from './holidays';
import { rateAt } from './rates';
import type { Cents, Client, Leave } from './types';

export type LeaveIndex = ReadonlyMap<ISODate, readonly Leave[]>;

export function indexLeaves(leaves: readonly Leave[]): LeaveIndex {
  const map = new Map<ISODate, Leave[]>();
  for (const leave of leaves) {
    const list = map.get(leave.date);
    if (list) list.push(leave);
    else map.set(leave.date, [leave]);
  }
  return map;
}

export function isActiveOn(client: Pick<Client, 'startDate' | 'endDate'>, date: ISODate): boolean {
  return client.startDate <= date && (client.endDate === null || date <= client.endDate);
}

export function isOnLeave(index: LeaveIndex | null, date: ISODate, clientId: string): boolean {
  if (!index) return false;
  return (index.get(date) ?? []).some((l) => l.scope === 'ALL' || l.clientId === clientId);
}

/** Le client TJM aurait été facturé ce jour-là, hors congés (conditions 1 à 3 de SPEC §4.1). */
export function worksOn(client: Client, date: ISODate): boolean {
  return (
    client.billingMode === 'TJM' &&
    isActiveOn(client, date) &&
    client.weekdays.includes(weekday(date)) &&
    !isHoliday(date)
  );
}

export function billableDays(client: Client, month: MonthKey, leaves: LeaveIndex | null): ISODate[] {
  if (client.billingMode !== 'TJM') return [];
  return eachDayOfMonth(month).filter((d) => worksOn(client, d) && !isOnLeave(leaves, d, client.id));
}

/** Montant facturé pour le mois (SPEC §4.1 et §4.3), arrondi au centime. `leaves = null` → sans congés. */
export function monthlyAmount(client: Client, month: MonthKey, leaves: LeaveIndex | null): Cents {
  if (client.billingMode === 'FORFAIT') {
    const n = daysInMonth(month);
    let total = 0;
    for (const d of eachDayOfMonth(month)) if (isActiveOn(client, d)) total += rateAt(client, d) / n;
    return Math.round(total);
  }
  return billableDays(client, month, leaves).reduce((sum, d) => sum + rateAt(client, d), 0);
}

import { addDays, diffDays, type ISODate, lastDayOfMonth, type MonthKey, monthKey } from './dates';
import type { Client, PaymentTerm } from './types';

export const PAYMENT_TERMS: Readonly<Record<PaymentTerm, { label: string; days: number; endOfMonth: boolean }>> = {
  RECEPTION: { label: 'À réception', days: 0, endOfMonth: false },
  NET_30: { label: '30 jours', days: 30, endOfMonth: false },
  NET_45: { label: '45 jours', days: 45, endOfMonth: false },
  EOM_30: { label: '30 j fin de mois', days: 30, endOfMonth: true },
  NET_60: { label: '60 jours', days: 60, endOfMonth: false },
};

export interface PaymentPath {
  workMonth: MonthKey;
  invoiceDate: ISODate;
  dueDate: ISODate;
  cashDate: ISODate;
  cashMonth: MonthKey;
  /** Jours entre la facture et l'encaissement */
  waitDays: number;
}

/** SPEC §4.4 : facture le dernier jour du mois, échéance selon le délai, encaissement = échéance + retard moyen. */
export function paymentPath(client: Pick<Client, 'paymentTerm' | 'averageDelayDays'>, workMonth: MonthKey): PaymentPath {
  const term = PAYMENT_TERMS[client.paymentTerm];
  const invoiceDate = lastDayOfMonth(workMonth);
  const raw = addDays(invoiceDate, term.days);
  const dueDate = term.endOfMonth ? lastDayOfMonth(monthKey(raw)) : raw;
  const cashDate = addDays(dueDate, client.averageDelayDays);
  return { workMonth, invoiceDate, dueDate, cashDate, cashMonth: monthKey(cashDate), waitDays: diffDays(invoiceDate, cashDate) };
}
```

import { addMonths, firstDayOfMonth, type ISODate, lastDayOfMonth, type MonthKey, monthRange } from './dates';
import { indexLeaves, monthlyAmount } from './billing';
import { paymentPath } from './payment';
import type { Cents, Client, Leave } from './types';

export const LOOKBACK_MONTHS = 8;

export interface IncomeEntry {
  clientId: string;
  workMonth: MonthKey;
  invoiceDate: ISODate;
  cashDate: ISODate;
  cashMonth: MonthKey;
  amount: Cents;
  amountWithoutLeaves: Cents;
  leaveCost: Cents;
}

export interface IncomeOptions {
  firstMonth: MonthKey;
  months: number;
  includeProspects: boolean;
  extraClients?: readonly Client[];
}

export function countedClients(clients: readonly Client[], includeProspects: boolean): Client[] {
  return clients.filter((c) => c.archivedAt === null && (includeProspects || !c.isProspect));
}

export function sumBy<T>(items: readonly T[], key: { [K in keyof T]: T[K] extends number ? K : never }[keyof T]): number {
  return items.reduce((sum, item) => sum + (item[key] as number), 0);
}

/** Encaissements dont le mois tombe dans [firstMonth, firstMonth + months[. */
export function projectIncome(clients: readonly Client[], leaves: readonly Leave[], opts: IncomeOptions): IncomeEntry[] {
  const index = indexLeaves(leaves);
  const lastMonth = addMonths(opts.firstMonth, opts.months - 1);
  const workMonths = monthRange(addMonths(opts.firstMonth, -LOOKBACK_MONTHS), opts.months + LOOKBACK_MONTHS);
  const entries: IncomeEntry[] = [];
  for (const client of [...countedClients(clients, opts.includeProspects), ...(opts.extraClients ?? [])]) {
    for (const workMonth of workMonths) {
      if (lastDayOfMonth(workMonth) < client.startDate) continue;
      if (client.endDate !== null && firstDayOfMonth(workMonth) > client.endDate) continue;
      const amountWithoutLeaves = monthlyAmount(client, workMonth, null);
      if (amountWithoutLeaves === 0) continue;
      const path = paymentPath(client, workMonth);
      if (path.cashMonth < opts.firstMonth || path.cashMonth > lastMonth) continue;
      const amount = monthlyAmount(client, workMonth, index);
      entries.push({
        clientId: client.id,
        workMonth,
        invoiceDate: path.invoiceDate,
        cashDate: path.cashDate,
        cashMonth: path.cashMonth,
        amount,
        amountWithoutLeaves,
        leaveCost: amountWithoutLeaves - amount,
      });
    }
  }
  return entries.sort((a, b) => a.cashDate.localeCompare(b.cashDate));
}
```

import type { RegulatoryParams } from './params';
import type { Cents, LegalStatus, SocialRegime } from './types';

export const REGIME_OF: Readonly<Record<LegalStatus, SocialRegime>> = {
  SASU: 'SALARIE', SAS: 'SALARIE', SASU_IR: 'SALARIE',
  SARL: 'TNS', EURL_IS: 'TNS', EURL_IR: 'TNS', EI: 'TNS',
  MICRO: 'MICRO',
};

export const LEGAL_STATUS_LABELS: Readonly<Record<LegalStatus, string>> = {
  SASU: 'SASU', SAS: 'SAS', SASU_IR: 'SASU à l’IR', SARL: 'SARL',
  EURL_IS: 'EURL à l’IS', EURL_IR: 'EURL à l’IR', EI: 'EI', MICRO: 'Micro',
};

export const REGIME_LABELS: Readonly<Record<SocialRegime, string>> = {
  SALARIE: 'Assimilé salarié',
  TNS: 'Indépendant (TNS)',
  MICRO: 'Micro-entreprise',
};

export const isCompanyStatus = (status: LegalStatus): boolean => status !== 'MICRO';

export function regimeTotal(net: Cents, regime: SocialRegime, params: RegulatoryParams): Cents {
  switch (regime) {
    case 'SALARIE':
      return Math.round(net * params.salarieCoef);
    case 'TNS':
      return Math.round(net * params.tnsCoef);
    case 'MICRO':
      return Math.round(net / (1 - params.microContributionRate));
  }
}

export function totalLabel(status: LegalStatus): string {
  if (status === 'MICRO') return 'CA à encaisser';
  if (status === 'EURL_IR' || status === 'EI') return 'Bénéfice nécessaire';
  return 'Coût pour la société';
}

export interface RemunerationCost {
  regime: SocialRegime;
  net: Cents;
  total: Cents;
  contributions: Cents;
  totalLabel: string;
}

/** SPEC §4.8. L'impôt sur le revenu n'est jamais compté. */
export function remunerationCost(net: Cents, status: LegalStatus, params: RegulatoryParams): RemunerationCost {
  const regime = REGIME_OF[status];
  const total = regimeTotal(net, regime, params);
  return { regime, net, total, contributions: total - net, totalLabel: totalLabel(status) };
}

export function remunerationComparison(net: Cents, params: RegulatoryParams): Array<{ regime: SocialRegime; label: string; total: Cents }> {
  return (['SALARIE', 'TNS', 'MICRO'] as const).map((regime) => ({ regime, label: REGIME_LABELS[regime], total: regimeTotal(net, regime, params) }));
}

import { type MonthKey, monthIndex, monthRange, yearOf } from './dates';
import { paramsFor, type RegulatoryParams } from './params';
import { remunerationCost } from './remuneration';
import type { Cents, Charge, ChargeFrequency, Profile } from './types';

export interface ChargeItem {
  id: string;
  name: string;
  amount: Cents;
  frequency: ChargeFrequency;
  month: number | null;
  category: string | null;
  /** true pour les deux lignes de rémunération calculées (lecture seule) */
  computed: boolean;
}

export const COMPUTED_NET_ID = 'computed:net';
export const COMPUTED_CONTRIBUTIONS_ID = 'computed:contributions';

export function remunerationLines(profile: Profile, params: RegulatoryParams): ChargeItem[] {
  if (profile.legalStatus === 'MICRO' || profile.netPayMonthly <= 0) return [];
  const cost = remunerationCost(profile.netPayMonthly, profile.legalStatus, params);
  return [
    { id: COMPUTED_NET_ID, name: 'Salaire (net)', amount: cost.net, frequency: 'MONTHLY', month: null, category: 'Toi', computed: true },
    { id: COMPUTED_CONTRIBUTIONS_ID, name: 'Cotisations sociales', amount: cost.contributions, frequency: 'MONTHLY', month: null, category: 'Social', computed: true },
  ];
}

/** SPEC §4.5 : charges du mois, triées par montant décroissant. */
export function chargesForMonth(charges: readonly Charge[], profile: Profile, month: MonthKey): ChargeItem[] {
  const m = monthIndex(month);
  const stored: ChargeItem[] = charges
    .filter((c) => c.frequency === 'MONTHLY' || c.month === m)
    .map((c) => ({ ...c, computed: false }));
  return [...remunerationLines(profile, paramsFor(yearOf(month))), ...stored].sort((a, b) => b.amount - a.amount);
}

export const monthlyEquivalent = (charge: Pick<Charge, 'amount' | 'frequency'>): Cents =>
  charge.frequency === 'MONTHLY' ? charge.amount : Math.round(charge.amount / 12);

export function chargesSummary(charges: readonly Charge[], profile: Profile, year: number): { monthlyAverage: Cents; annualTotal: Cents } {
  const annualTotal = monthRange(`${year}-01`, 12).reduce(
    (sum, month) => sum + chargesForMonth(charges, profile, month).reduce((s, c) => s + c.amount, 0),
    0,
  );
  return { annualTotal, monthlyAverage: Math.round(annualTotal / 12) };
}

import { chargesForMonth, type ChargeItem } from './charges';
import { type MonthKey, monthKey, monthRange } from './dates';
import { type IncomeEntry, projectIncome, sumBy } from './income';
import type { Cents, Client, EngineInput } from './types';

export const HORIZON_MONTHS = 15;

export type MonthState = 'POSITIVE' | 'RED' | 'RED_DUE_TO_LEAVES' | 'OVERDRAFT';

export interface MonthResult {
  month: MonthKey;
  income: Cents;
  incomeWithoutLeaves: Cents;
  leaveCost: Cents;
  charges: Cents;
  chargeItems: ChargeItem[];
  entries: IncomeEntry[];
  result: Cents;
  resultWithoutLeaves: Cents;
  balance: Cents;
  balanceWithoutLeaves: Cents;
  state: MonthState;
}

export interface ResultsOptions {
  includeProspects?: boolean;
  months?: number;
  extraClients?: readonly Client[];
}

/** SPEC §4.7 */
export function monthState(r: Pick<MonthResult, 'result' | 'resultWithoutLeaves' | 'balance'>): MonthState {
  if (r.balance < 0) return 'OVERDRAFT';
  if (r.result < 0) return r.resultWithoutLeaves >= 0 ? 'RED_DUE_TO_LEAVES' : 'RED';
  return 'POSITIVE';
}

/** Projection sur 15 mois à partir du mois de `today`. Le solde initial s'applique au début du mois courant. */
export function monthResults(input: EngineInput, opts: ResultsOptions = {}): MonthResult[] {
  const months = opts.months ?? HORIZON_MONTHS;
  const firstMonth = monthKey(input.today);
  const entries = projectIncome(input.clients, input.leaves, {
    firstMonth,
    months,
    includeProspects: opts.includeProspects ?? input.profile.includeProspects,
    extraClients: opts.extraClients,
  });
  let balance = input.balance?.amount ?? 0;
  let balanceWithoutLeaves = balance;
  return monthRange(firstMonth, months).map((month) => {
    const monthEntries = entries.filter((e) => e.cashMonth === month);
    const income = sumBy(monthEntries, 'amount');
    const incomeWithoutLeaves = sumBy(monthEntries, 'amountWithoutLeaves');
    const chargeItems = chargesForMonth(input.charges, input.profile, month);
    const charges = sumBy(chargeItems, 'amount');
    const result = income - charges;
    const resultWithoutLeaves = incomeWithoutLeaves - charges;
    balance += result;
    balanceWithoutLeaves += resultWithoutLeaves;
    const partial = { result, resultWithoutLeaves, balance };
    return {
      month, income, incomeWithoutLeaves, leaveCost: incomeWithoutLeaves - income,
      charges, chargeItems, entries: monthEntries, result, resultWithoutLeaves,
      balance, balanceWithoutLeaves, state: monthState(partial),
    };
  });
}

export interface ResultsSummary {
  redCount: number;
  overdraftCount: number;
  redDueToLeavesCount: number;
  lowestBalance: Cents;
  lowestBalanceMonth: MonthKey | null;
  text: string;
}

export function resultsSummary(results: readonly MonthResult[]): ResultsSummary {
  const redCount = results.filter((r) => r.result < 0).length;
  const overdraftCount = results.filter((r) => r.balance < 0).length;
  const redDueToLeavesCount = results.filter((r) => r.state === 'RED_DUE_TO_LEAVES').length;
  let lowest: MonthResult | null = null;
  for (const r of results) if (!lowest || r.balance < lowest.balance) lowest = r;
  const text =
    overdraftCount > 0
      ? `${overdraftCount} mois à découvert`
      : redCount === 0
        ? 'Aucun mois dans le rouge'
        : `${redCount} mois dans le rouge, jamais à découvert`;
  return { redCount, overdraftCount, redDueToLeavesCount, lowestBalance: lowest?.balance ?? 0, lowestBalanceMonth: lowest?.month ?? null, text };
}

import { worksOn } from './billing';
import { addDays, eachDay, type ISODate, type MonthKey, monthKey } from './dates';
import { isWorkingDay } from './holidays';
import { countedClients } from './income';
import { paymentPath } from './payment';
import { rateAt } from './rates';
import type { Cents, Client, EngineInput, Leave, LeaveScope } from './types';

export const workingDaysBetween = (from: ISODate, to: ISODate): ISODate[] => eachDay(from, to).filter(isWorkingDay);

export interface LeaveDayImpact {
  clientId: string;
  date: ISODate;
  cost: Cents;
  cashMonth: MonthKey;
}

/** SPEC §4.6 : coût d'un jour de congé et mois d'impact, pour des clients déjà filtrés (pistes, archivés). */
export function leaveImpact(leave: Leave, clients: readonly Client[]): LeaveDayImpact[] {
  return clients
    .filter((c) => worksOn(c, leave.date) && (leave.scope === 'ALL' || c.id === leave.clientId))
    .map((c) => ({ clientId: c.id, date: leave.date, cost: rateAt(c, leave.date), cashMonth: paymentPath(c, monthKey(leave.date)).cashMonth }));
}

export function leavesCost(leaves: readonly Leave[], clients: readonly Client[], includeProspects: boolean): Cents {
  const counted = countedClients(clients, includeProspects);
  return leaves.reduce((sum, l) => sum + leaveImpact(l, counted).reduce((s, i) => s + i.cost, 0), 0);
}

export interface LeavePeriod {
  key: string;
  from: ISODate;
  to: ISODate;
  dates: ISODate[];
  leaveIds: string[];
  scope: LeaveScope;
  clientId: string | null;
  dayCount: number;
  cost: Cents;
  impacts: Array<{ cashMonth: MonthKey; amount: Cents }>;
}

function hasWorkingDayBetween(a: ISODate, b: ISODate): boolean {
  for (let d = addDays(a, 1); d < b; d = addDays(d, 1)) if (isWorkingDay(d)) return true;
  return false;
}

export function groupLeaves(input: Pick<EngineInput, 'clients' | 'leaves' | 'profile'>, opts: { includeProspects?: boolean } = {}): LeavePeriod[] {
  const counted = countedClients(input.clients, opts.includeProspects ?? input.profile.includeProspects);
  const allDates = new Set(input.leaves.filter((l) => l.scope === 'ALL').map((l) => l.date));
  const byKey = new Map<string, Leave[]>();
  for (const leave of input.leaves) {
    const key = leave.scope === 'ALL' ? 'ALL' : `CLIENT:${leave.clientId}`;
    byKey.set(key, [...(byKey.get(key) ?? []), leave]);
  }

  const build = (key: string, list: Leave[]): LeavePeriod => {
    const first = list[0]!;
    const impacts = new Map<MonthKey, Cents>();
    let cost = 0;
    for (const leave of list) {
      if (leave.scope === 'CLIENT' && allDates.has(leave.date)) continue;
      for (const imp of leaveImpact(leave, counted)) {
        cost += imp.cost;
        impacts.set(imp.cashMonth, (impacts.get(imp.cashMonth) ?? 0) + imp.cost);
      }
    }
    return {
      key: `${key}:${first.date}`,
      from: first.date,
      to: list[list.length - 1]!.date,
      dates: list.map((l) => l.date),
      leaveIds: list.flatMap((l) => (l.id ? [l.id] : [])),
      scope: first.scope,
      clientId: first.clientId,
      dayCount: list.length,
      cost,
      impacts: [...impacts.entries()].sort(([a], [b]) => a.localeCompare(b)).map(([cashMonth, amount]) => ({ cashMonth, amount })),
    };
  };

  const periods: LeavePeriod[] = [];
  for (const [key, list] of byKey) {
    const sorted = [...list].sort((a, b) => a.date.localeCompare(b.date));
    let current: Leave[] = [];
    for (const leave of sorted) {
      const prev = current[current.length - 1];
      if (prev && prev.date === leave.date) continue;
      if (prev && hasWorkingDayBetween(prev.date, leave.date)) {
        periods.push(build(key, current));
        current = [];
      }
      current.push(leave);
    }
    if (current.length) periods.push(build(key, current));
  }
  return periods.sort((a, b) => a.from.localeCompare(b.from) || a.key.localeCompare(b.key));

import { addMonths, firstDayOfMonth, type ISODate, type MonthKey, monthKey, monthRange, yearOf } from './dates';
import { type IncomeEntry, projectIncome, sumBy } from './income';
import { paramsFor, type RegulatoryParams } from './params';
import { HORIZON_MONTHS } from './results';
import type { Cents, Client, EngineInput, Profile } from './types';

export interface MicroBreakdown {
  income: Cents;
  contributions: Cents;
  tax: Cents;
  proExpenses: Cents;
  forYou: Cents;
}

/** SPEC §4.9 */
export function microBreakdown(income: Cents, profile: Profile, params: RegulatoryParams): MicroBreakdown {
  const contributions = Math.round(income * params.microContributionRate);
  const taxRate = profile.microVersementLiberatoire ? params.microVersementLiberatoireRate : profile.microIncomeTaxProvisionPct / 100;
  const tax = Math.round(income * taxRate);
  const proExpenses = profile.microProExpensesMonthly;
  return { income, contributions, tax, proExpenses, forYou: income - contributions - tax - proExpenses };
}

export const TEST_MISSION_ID = 'test-mission';

/** Mission hypothétique : lundi, 650 €/j, dès le mois suivant, payée à 30 jours. */
export function testMissionClient(today: ISODate): Client {
  const start = firstDayOfMonth(addMonths(monthKey(today), 1));
  return {
    id: TEST_MISSION_ID, name: 'Mission test', subtitle: null, color: 'indigo', billingMode: 'TJM', weekdays: [0],
    startDate: start, endDate: null, paymentTerm: 'NET_30', averageDelayDays: 0, isProspect: false, archivedAt: null,
    rates: [{ validFrom: start, amount: 65_000 }],
  };
}

export interface MicroMonth {
  month: MonthKey;
  income: Cents;
  entries: IncomeEntry[];
  breakdown: MicroBreakdown;
}

export function microMonths(input: EngineInput, opts: { firstMonth?: MonthKey; months?: number; testMission?: boolean } = {}): MicroMonth[] {
  const firstMonth = opts.firstMonth ?? monthKey(input.today);
  const months = opts.months ?? HORIZON_MONTHS;
  const entries = projectIncome(input.clients, input.leaves, {
    firstMonth,
    months,
    includeProspects: input.profile.includeProspects,
    extraClients: opts.testMission ? [testMissionClient(input.today)] : [],
  });
  return monthRange(firstMonth, months).map((month) => {
    const monthEntries = entries.filter((e) => e.cashMonth === month);
    const income = sumBy(monthEntries, 'amount');
    return { month, income, entries: monthEntries, breakdown: microBreakdown(income, input.profile, paramsFor(yearOf(month))) };
  });
}

export type GaugeLevel = 'OK' | 'WARN' | 'OVER';

export interface CeilingGauge {
  year: number;
  actual: Cents;
  planned: Cents;
  total: Cents;
  ceiling: Cents;
  pct: number;
  level: GaugeLevel;
  overMonth: MonthKey | null;
  vatThreshold: Cents;
  vatMonth: MonthKey | null;
}

/** Jauge du plafond pour l'année civile : réel = mois passés, prévu = mois courant et suivants. */
export function ceilingGauge(input: EngineInput, year: number, opts: { testMission?: boolean } = {}): CeilingGauge {
  const params = paramsFor(year);
  const current = monthKey(input.today);
  const months = microMonths(input, { firstMonth: `${year}-01`, months: 12, testMission: opts.testMission });
  let actual = 0;
  let planned = 0;
  let cumulative = 0;
  let overMonth: MonthKey | null = null;
  let vatMonth: MonthKey | null = null;
  for (const m of months) {
    if (m.month < current) actual += m.income;
    else planned += m.income;
    cumulative += m.income;
    if (!overMonth && cumulative > params.microCeiling) overMonth = m.month;
    if (!vatMonth && cumulative > params.vatThreshold) vatMonth = m.month;
  }
  const total = actual + planned;
  const pct = Math.round((total / params.microCeiling) * 100);
  const level: GaugeLevel = overMonth ? 'OVER' : pct > 85 ? 'WARN' : 'OK';
  return { year, actual, planned, total, ceiling: params.microCeiling, pct, level, overMonth, vatThreshold: params.vatThreshold, vatMonth };
}

/** Revenu lissé : moyenne de « pour toi » sur les 12 premiers mois ; mois sous 60 % signalés. */
export function smoothedIncome(months: readonly MicroMonth[]): { average: Cents; lowMonths: MonthKey[] } {
  const first12 = months.slice(0, 12);
  const average = first12.length ? Math.round(first12.reduce((s, m) => s + m.breakdown.forYou, 0) / first12.length) : 0;
  return { average, lowMonths: months.filter((m) => m.breakdown.forYou < average * 0.6).map((m) => m.month) };
}

import { indexLeaves, monthlyAmount } from './billing';
import { diffDays, firstDayOfMonth, type ISODate, lastDayOfMonth, maxDate, minDate, type MonthKey, monthKey, monthRange } from './dates';
import { countedClients, projectIncome } from './income';
import { type PaymentPath, paymentPath } from './payment';
import { currentRate } from './rates';
import type { Cents, Client, EngineInput } from './types';

export function estimatedMonthly(client: Client, today: ISODate): Cents {
  const rate = currentRate(client, today)?.amount ?? 0;
  return client.billingMode === 'FORFAIT' ? rate : Math.round(client.weekdays.length * 4.3 * rate);
}

export const estimatedDaysPerMonth = (client: Client): number => Math.round(client.weekdays.length * 4.3);

export interface TimelineBar {
  clientId: string;
  leftPct: number;
  widthPct: number;
  openEnd: boolean;
  visible: boolean;
}

export interface MissionTimeline {
  months: MonthKey[];
  bars: TimelineBar[];
  /** Montant facturé (hors congés) par mois de la fenêtre */
  billed: Cents[];
  lowMonths: MonthKey[];
}

export function missionTimeline(input: EngineInput, opts: { months?: number; includeProspects?: boolean } = {}): MissionTimeline {
  const n = opts.months ?? 12;
  const months = monthRange(monthKey(input.today), n);
  const winStart = firstDayOfMonth(months[0]!);
  const winEnd = lastDayOfMonth(months[n - 1]!);
  const span = diffDays(winStart, winEnd) + 1;
  const bars = input.clients
    .filter((c) => c.archivedAt === null)
    .map((c): TimelineBar => {
      const s = maxDate(c.startDate, winStart);
      const e = c.endDate === null ? winEnd : minDate(c.endDate, winEnd);
      const visible = s <= e;
      return {
        clientId: c.id,
        leftPct: visible ? (diffDays(winStart, s) / span) * 100 : 0,
        widthPct: visible ? ((diffDays(s, e) + 1) / span) * 100 : 0,
        openEnd: c.endDate === null || c.endDate > winEnd,
        visible,
      };
    });
  const counted = countedClients(input.clients, opts.includeProspects ?? input.profile.includeProspects);
  const billed = months.map((m) => counted.reduce((s, c) => s + monthlyAmount(c, m, null), 0));
  const best = Math.max(0, ...billed);
  const lowMonths = best > 0 ? months.filter((_, i) => billed[i]! < best * 0.75) : [];
  return { months, bars, billed, lowMonths };
}

export interface CashMonth {
  month: MonthKey;
  billed: Record<string, Cents>;
  cashed: Record<string, Cents>;
  billedTotal: Cents;
  cashedTotal: Cents;
}

export function billedVsCashed(input: EngineInput, opts: { months?: number; includeProspects?: boolean } = {}): CashMonth[] {
  const n = opts.months ?? 12;
  const first = monthKey(input.today);
  const includeProspects = opts.includeProspects ?? input.profile.includeProspects;
  const counted = countedClients(input.clients, includeProspects);
  const index = indexLeaves(input.leaves);
  const entries = projectIncome(input.clients, input.leaves, { firstMonth: first, months: n, includeProspects });
  return monthRange(first, n).map((month) => {
    const billed: Record<string, Cents> = {};
    for (const c of counted) {
      const amount = monthlyAmount(c, month, index);
      if (amount) billed[c.id] = amount;
    }
    const cashed: Record<string, Cents> = {};
    for (const e of entries) if (e.cashMonth === month) cashed[e.clientId] = (cashed[e.clientId] ?? 0) + e.amount;
    const total = (r: Record<string, Cents>) => Object.values(r).reduce((s, v) => s + v, 0);
    return { month, billed, cashed, billedTotal: total(billed), cashedTotal: total(cashed) };
  });
}

/** « Le chemin d'une facture » : premier mois facturé dans les 12 mois, sinon mois de début (ou courant). */
export function firstInvoicePath(client: Client, today: ISODate): PaymentPath {
  const first = monthKey(today);
  for (const m of monthRange(first, 12)) if (monthlyAmount(client, m, null) > 0) return paymentPath(client, m);
  return paymentPath(client, maxDate(first, monthKey(client.startDate)));
}

function templateClients(clients: readonly Client[], today: ISODate): Client[] {
  return clients.filter(
    (c) => c.billingMode === 'TJM' && c.archivedAt === null && !c.isProspect && (c.endDate === null || c.endDate >= today),
  );
}

export function weekTemplate(clients: readonly Client[], today: ISODate): Array<{ weekday: number; clientId: string | null }> {
  const eligible = templateClients(clients, today);
  return [0, 1, 2, 3, 4].map((weekday) => ({ weekday, clientId: eligible.find((c) => c.weekdays.includes(weekday))?.id ?? null }));
}

/** Semaine type mobile : fait tourner le jour vers le client suivant, puis « libre », puis le premier client. */
export function cycleWeekday(clients: readonly Client[], today: ISODate, weekday: number): Array<{ clientId: string; weekdays: number[] }> {
  const eligible = templateClients(clients, today);
  const currentIdx = eligible.findIndex((c) => c.weekdays.includes(weekday));
  const next = currentIdx === -1 ? eligible[0] : eligible[currentIdx + 1];
  const patches: Array<{ clientId: string; weekdays: number[] }> = [];
  const current = eligible[currentIdx];
  if (current) patches.push({ clientId: current.id, weekdays: current.weekdays.filter((d) => d !== weekday) });
  if (next) patches.push({ clientId: next.id, weekdays: [...next.weekdays, weekday].sort((x, y) => x - y) });
  return patches;
}

export type LeaveTarget = { scope: 'ALL' } | { scope: 'CLIENT'; clientId: string };

export const matchesTarget = (leave: Leave, target: LeaveTarget): boolean =>
  target.scope === 'ALL' ? leave.scope === 'ALL' : leave.scope === 'CLIENT' && leave.clientId === target.clientId;

export interface CalendarDay {
  date: ISODate;
  inMonth: boolean;
  weekend: boolean;
  holidayName: string | null;
  /** Clients TJM comptés qui travailleraient ce jour-là */
  clientIds: string[];
  /** Tous les congés posés ce jour-là */
  leaves: Leave[];
  /** Congé correspondant au sélecteur « Poser chez » (à retirer au clic), sinon null */
  targetLeave: Leave | null;
  clickable: boolean;
}

export function calendarMonth(input: EngineInput, month: MonthKey, target: LeaveTarget, opts: { includeProspects?: boolean } = {}): CalendarDay[] {
  const counted = countedClients(input.clients, opts.includeProspects ?? input.profile.includeProspects);
  const index = indexLeaves(input.leaves);
  const first = firstDayOfMonth(month);
  const last = lastDayOfMonth(month);
  const gridStart = addDays(first, -weekday(first));
  const gridEnd = addDays(last, 6 - weekday(last));
  return eachDay(gridStart, gridEnd).map((date) => {
    const leaves = [...(index.get(date) ?? [])];
    const inMonth = monthKey(date) === month;
    return {
      date,
      inMonth,
      weekend: weekday(date) >= 5,
      holidayName: holidayName(date),
      clientIds: counted.filter((c) => worksOn(c, date)).map((c) => c.id),
      leaves,
      targetLeave: leaves.find((l) => matchesTarget(l, target)) ?? null,
      clickable: inMonth && isWorkingDay(date),
    };
  });
}

export interface LeaveKpis {
  dayCount: number;
  lostIncome: Cents;
  lowestBalance: Cents;
  lowestBalanceMonth: MonthKey | null;
  riskCount: number;
  overdraftCount: number;
  dueToLeavesCount: number;
}

export function leaveKpis(input: EngineInput, results: readonly MonthResult[]): LeaveKpis {
  if (results.length === 0) {
    return { dayCount: 0, lostIncome: 0, lowestBalance: 0, lowestBalanceMonth: null, riskCount: 0, overdraftCount: 0, dueToLeavesCount: 0 };
  }
  const from = firstDayOfMonth(results[0]!.month);
  const to = lastDayOfMonth(results[results.length - 1]!.month);
  let lowest = results[0]!;
  for (const r of results) if (r.balance < lowest.balance) lowest = r;
  return {
    dayCount: new Set(input.leaves.filter((l) => l.date >= from && l.date <= to).map((l) => l.date)).size,
    lostIncome: results.reduce((s, r) => s + r.leaveCost, 0),
    lowestBalance: lowest.balance,
    lowestBalanceMonth: lowest.month,
    riskCount: results.filter((r) => r.result < 0 || r.balance < 0).length,
    overdraftCount: results.filter((r) => r.balance < 0).length,
    dueToLeavesCount: results.filter((r) => r.state === 'RED_DUE_TO_LEAVES').length,
  };
}

import { diffDays, type ISODate, type MonthKey, monthIndex, yearOf } from './dates';
import type { BillingMode, Cents } from './types';

const MINUS = '−';
const NBSP = ' ';

export const MONTHS_LONG = ['janvier', 'février', 'mars', 'avril', 'mai', 'juin', 'juillet', 'août', 'septembre', 'octobre', 'novembre', 'décembre'] as const;
export const MONTHS_SHORT = ['janv.', 'févr.', 'mars', 'avr.', 'mai', 'juin', 'juil.', 'août', 'sept.', 'oct.', 'nov.', 'déc.'] as const;

const group = (n: number): string => n.toLocaleString('fr-FR');

/** Montant arrondi à la dizaine d'euros : « −2 310 € ». */
export function euros(cents: Cents, opts: { sign?: boolean } = {}): string {
  const tens = Math.round(Math.abs(cents) / 1000) * 10;
  const prefix = tens === 0 ? '' : cents < 0 ? MINUS : opts.sign ? '+' : '';
  return `${prefix}${group(tens)}${NBSP}€`;
}

/** Montant à l'euro près (tarifs, saisies) : « 1 200 € ». */
export function eurosExact(cents: Cents): string {
  const value = Math.round(Math.abs(cents) / 100);
  return `${cents < 0 && value !== 0 ? MINUS : ''}${group(value)}${NBSP}€`;
}

/** Libellé de graphique : « +5,3k ». */
export function kEuros(cents: Cents, opts: { sign?: boolean } = {}): string {
  const value = (Math.abs(cents) / 100_000).toFixed(1).replace('.', ',');
  const signed = opts.sign ?? true;
  const prefix = cents < 0 ? MINUS : signed ? '+' : '';
  return `${prefix}${value}k`;
}

export const monthName = (month: MonthKey): string => MONTHS_LONG[monthIndex(month)]!;
export const monthLabel = (month: MonthKey): string => `${monthName(month)} ${yearOf(month)}`;
export const monthShort = (month: MonthKey): string => MONTHS_SHORT[monthIndex(month)]!;
export const monthLetter = (month: MonthKey): string => monthName(month).charAt(0).toUpperCase();

const dayLabel = (iso: ISODate): string => {
  const d = Number(iso.slice(8, 10));
  return d === 1 ? '1er' : String(d);
};

export const shortDate = (iso: ISODate): string => `${dayLabel(iso)} ${MONTHS_SHORT[monthIndex(iso)]}`;
export const longDate = (iso: ISODate): string => `${dayLabel(iso)} ${MONTHS_LONG[monthIndex(iso)]} ${yearOf(iso)}`;

export function relativeDays(from: ISODate, today: ISODate): string {
  const n = diffDays(from, today);
  if (n <= 0) return 'aujourd’hui';
  if (n === 1) return 'hier';
  return `il y a ${n} jours`;
}

/** « Facture d’octobre · vers le 30 nov. » */
export function invoiceLabel(entry: { workMonth: MonthKey; cashDate: ISODate }, billingMode: BillingMode): string {
  const name = monthName(entry.workMonth);
  const of = /^[aeiouy]/.test(name) ? 'd’' : 'de ';
  return `${billingMode === 'FORFAIT' ? 'Forfait' : 'Facture'} ${of}${name} · vers le ${shortDate(entry.cashDate)}`;
}

export const plural = (n: number, singular: string, pluralForm = `${singular}s`): string => `${n} ${n > 1 ? pluralForm : singular}`;
