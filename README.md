# Cresus

Caisse de buvette pour les associations de parents d'élèves (APE) : un gros bouton par article, un appui = une vente. Chaque évènement (kermesse, marché de Noël…) a ses articles, son bilan et son export Excel.

La conception est décrite dans [`docs/superpowers/specs/2026-11-15-cresus-caisse-design.md`](docs/superpowers/specs/2026-11-15-cresus-caisse-design.md).
